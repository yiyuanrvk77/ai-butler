# AI 管家 · 全年龄家庭助手（演示版）

一个跑在你自己电脑上的「家庭 AI 管家」，目标是帮家人记住每一件小事：

- 💬 陪家人聊天
- 💊 记住吃药安排，到点提醒
- 📖 记住家人的喜好和小事（比如"喜欢喝绿茶"）
- 📊 记录血压、血糖
- 🔠 大字模式，适合长辈使用

## 怎么打开

**方式一（最简单）**：双击 `index.html`，用 Chrome 或 Edge 打开即可。默认"模拟模式"，离线也能玩。

**方式二（推荐）**：双击 `启动.bat`，会自动启动本地服务并打开浏览器。这种方式可以接入真实 AI。需要电脑装了 Python（一般都有）。

## 第一次使用

1. 点右上角「设置」，填家人称呼（比如"爸爸"），可以改管家名字和性格。
2. 切到「吃药提醒」，点「添加药品」，填药名、用量和时间，比如：阿司匹林，每天 08:00, 12:30, 18:30。
3. 到点后页面会弹提醒、响铃；点「我吃过了」就记下来了。
4. 在聊天里直接说：
   - "我叫王大明"
   - "我喜欢喝绿茶"
   - "血压 130/85"
   管家会自动记住，到「记忆本」里就能看到。

## 内嵌版：把管家放进任何网站

除了独立打开，管家还能以一个小组件的形式嵌进任意网页，任何网站的访客都能用：

```html
<script src="butler-widget.js" data-butler-name="小管家" data-color="#e8865a"></script>
```

- `butler-widget.js`：完整的小组件，自带样式，不需要别的文件
- 右下角会出现管家按钮，点开即可聊天；访客说过的喜好会自动记住
- 记忆存在每位访客自己的浏览器里（每个网站各一份），网站方看不到
- 想接真实 AI，在引入脚本前定义：

```html
<script>
  window.__BUTLER_CONFIG = { api: { baseUrl: "https://api.deepseek.com/v1", model: "deepseek-chat", key: "你的密钥" } };
</script>
<script src="butler-widget.js"></script>
```

打开 `demo.html` 可以看嵌入效果。注意：网页直连模型接口可能受浏览器跨域限制，正式上线时建议通过自己的后端转发（参考 `server.py` 的做法）。

这个内嵌版相当于"管家内核"，用药提醒、健康记录等完整功能在独立版里有。下一步可以把它升级成真正的平台：加账号系统，让同一个管家在网站、小程序、App 里都跟着同一个用户走。

## 接入真实 AI（可选）

设置里选「真实 AI」，填接口地址、模型名和密钥。支持 OpenAI 以及所有 OpenAI 兼容接口，比如：

| 服务 | 接口地址 | 模型示例 |
|------|---------|---------|
| OpenAI | https://api.openai.com/v1 | gpt-4o-mini |
| DeepSeek | https://api.deepseek.com/v1 | deepseek-chat |
| 智谱 | https://open.bigmodel.cn/api/paas/v4 | glm-4-flash |
| Kimi | https://api.moonshot.cn/v1 | moonshot-v1-8k |

不填也能用，内置的"模拟模式"足够演示和日常简单使用。

## 数据安全

所有数据（聊天记录、用药安排、记忆、血压血糖）都只保存在这台电脑的浏览器本地，不联网、不上传。模型密钥也只存在本机。

## 提醒的局限（重要）

目前的提醒是"页面开着才会响"。想真正到点叫醒家人（比如微信/手机推送、语音播报），是下一步要做的事，需要接入推送服务。

## 下一步可以加什么

- 微信 / 手机推送提醒，真正"到点就叫"
- 每天聊天自动总结，生成"今日摘要"给家人看
- 血压、血糖趋势图（折线）
- 语音播报："该吃药啦"
- 多人档案：爸妈、孩子各有各的记忆和提醒

## 技术说明（给开发者）

纯前端单页应用（HTML / CSS / JavaScript），无框架、无依赖，数据用浏览器 localStorage。
`server.py` 是 Python 标准库写的静态服务器 + 模型接口代理，用来绕开浏览器的跨域限制。改动非常容易，直接编辑文件即可。
