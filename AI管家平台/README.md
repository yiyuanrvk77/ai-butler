# AI 管家 · 平台版（多用户）

这是"AI 管家"的平台版本：**全年龄**——同一个平台，让每个年龄段都找到适合自己的陪伴形态：年轻人找 AI 朋友/对象/偶像，中年人找情感寄托和家庭秘书，长辈找健康管家，孩子找知心哥哥/姐姐。

**任何人都能注册一个账号，领到自己的专属管家**。每个用户可以有多个角色，每个角色都有自己的记忆，互不串味。

## 现在能做什么

- 👤 **账号系统**：注册、登录、退出，密码加密存储
- 👨‍👩‍👧‍👦 **家人档案**：可以添加家人（爸爸、爷爷、孩子…），给每个人单独记药；选中"长辈"自动切大字
- 🎭 **全年龄角色系统**：内置 11 个角色，按人群分类——年轻人（温柔女友/毒舌朋友/督学学姐/追星同好）、中年人（养生顾问/树洞朋友/家庭秘书）、长辈（健康管家）、儿童（知心哥哥/知心姐姐）、通用（暖心管家）；注册时选身份，平台自动推荐对应角色，也可以自己创建任意角色
- 🧠 **记忆系统**：每个用户 × 每个角色一套独立记忆；聊天时说"我喜欢喝绿茶""我血压 130/85"，管家自动记住，也能手动记、删
- 💬 **聊天**：带着记忆聊天；内置模拟回复开箱即用，也可以接真实大模型
- 💊 **用药提醒**：添加药品和时间，显示"下次吃药"，标记"我吃过了"
- ⏰ **到点提醒**：页面开着时，到点会自动弹窗、响铃，点"我吃过了"就记进健康记录
- 📋 **每日关怀摘要**：一个"今日"页，汇总全家今天谁吃了什么药、谁没吃、今日血压血糖、明天要记什么
- 📈 **健康趋势图**：血压、血糖在聊天里报数（"血压 130/85"），自动记录并画成折线图
- 🔒 **用户隔离**：A 用户聊了什么、记了什么，B 用户完全看不到

## 怎么启动

1. 双击 `启动.bat`（需要电脑装了 Python）
2. 浏览器会自动打开 http://127.0.0.1:8001
3. 注册一个账号，选一个角色，开始聊天

也可以手动启动：在该目录运行 `python server.py`。

## 第一次使用

1. 注册账号（用户名 + 密码 + 选择你的身份：年轻人/中年人/长辈/孩子）
2. 平台会按身份推荐角色，左侧"我的角色"也可以按人群筛选
3. 「家人」点"＋ 添加家人"，比如把爸爸加进来；选中他后给他添加药品和时间，到点试试弹窗提醒
4. 聊天里试试：
   - "我叫王大明，我喜欢喝绿茶"
   - "我血压 130/85"
   - "你记得我什么？"
5. 切到「今日」标签看每日关怀摘要和健康趋势
6. 切到「记忆」标签看管家记住了什么

## 接真实 AI（可选）

编辑同目录下的 `config.json`，填上模型接口（密钥只存在这台电脑上，不会发给浏览器）：

```json
{
  "llm": {
    "baseUrl": "https://api.deepseek.com/v1",
    "model": "deepseek-chat",
    "key": "你的密钥"
  }
}
```

支持 OpenAI 以及所有 OpenAI 兼容接口（DeepSeek、智谱、Kimi、通义等）。不填也能用，内置"模拟回复"足够演示。

## 数据存在哪里

所有数据（账号、记忆、聊天、用药）都在同目录的 `platform.db`（SQLite 单文件数据库）里。密码用加盐哈希存储，会话用随机令牌。整个平台目前只监听本机（127.0.0.1），别人访问不到。

## 技术架构（给开发者）

- 后端：Python 标准库（http.server + sqlite3），零第三方依赖
- 前端：原生 HTML / CSS / JavaScript，无框架
- 数据模型：users / sessions / members / personas / memories / messages / meds / med_doses
- 记忆按 `user_id + persona_id` 隔离
- 内置角色 `user_id=0` 为平台角色，用户自建角色 `user_id=本人`

## 下一步路线

- 📱 **手机/微信推送**：让提醒真正"叫醒"家人，不用一直开着页面
- 🏪 **角色商店**：用户创建的角色可以公开分享，别人一键领养
- ☁️ **部署上线**：放到云服务器，让任何人通过网址访问
- 🗣️ **语音**：让管家开口说话、语音输入
- 🧠 **每个家人的独立记忆和聊天**（目前记忆按账号、用药按人，下一步让记忆也按人）
- 🧒 **儿童安全**：儿童角色的内容边界（不含恋爱向、诱导消费等），以及家长监管页
- 🎨 **按人群换界面风格**：儿童更可爱、长辈更大字、年轻人更时尚
- 💳 **付费与合规**：注册校验、内容过滤、支付（做大了才需要）
