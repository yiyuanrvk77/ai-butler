# AI 管家 · 全年龄 AI 陪伴与家庭管家平台

一个"全年龄"的 AI 管家：年轻人找 AI 朋友/对象/偶像，中年人找情感寄托和家庭秘书，长辈找健康管家，孩子找知心哥哥/姐姐。**同一个平台，让每个年龄段都找到适合自己的陪伴形态。**

## 仓库结构

```
AI管家/        单机版 —— 双击即用，数据存在浏览器本地
AI管家平台/    平台版 —— 多用户、账号系统、角色、记忆、用药提醒、每日关怀（推荐）
```

平台版功能：

- 👤 账号系统（注册 / 登录 / 退出，密码加密）
- 👨‍👩‍👧‍👦 家人档案（给每个人单独记药，长辈自动大字）
- 🎭 全年龄角色系统（11 个内置角色 + 用户自建，按人群分类）
- 🧠 记忆系统（每个用户 × 每个角色独立记忆，自动提取喜好与健康数据）
- 💊 用药提醒（到点弹窗响铃，"我吃过了"记录在案）
- 📋 每日关怀摘要（今天谁吃药了、血压血糖、明天要记什么）
- 📈 健康趋势图（血压 / 血糖折线）
- 🔒 用户隔离与数据本地存储

## 快速开始

1. 电脑需要 Python 3
2. 双击 `AI管家平台/启动.bat`，浏览器自动打开 http://127.0.0.1:8001
3. 注册账号，选择身份，添加家人和药品，开始使用

也可以双击 `AI管家/index.html` 体验单机版（无需服务器）。

## 接真实 AI（可选）

平台版复制 `config.example.json` 为 `config.json`，填入模型接口（密钥只存在本机，不会上传到 GitHub）：

```json
{
  "llm": {
    "baseUrl": "https://api.deepseek.com/v1",
    "model": "deepseek-chat",
    "key": "你的密钥"
  }
}
```

支持 OpenAI 及所有 OpenAI 兼容接口（DeepSeek、智谱、Kimi、通义等）。不填也能用内置模拟回复。

## 技术栈

- 后端：Python 标准库（http.server + sqlite3），零第三方依赖
- 前端：原生 HTML / CSS / JavaScript，无框架
- 数据：SQLite 单文件（`platform.db`，已在 .gitignore 中排除）
